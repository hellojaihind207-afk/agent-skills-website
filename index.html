    How it works
    
One format, three ways in

    
Agent Skills is a portable Markdown workflow format. Your agent decides how SKILL.md files are discovered and run.

    

      
1
Skills
Workflow instructions such as TDD, code review and security hardening. Processes, not static docs.

      
2
Native integration
Use your agent’s own plugin mechanism where one is documented.

      
3
Universal CLI
One npx skills add command reaches 70+ agents.

    

    
Important: Don’t copy the repo’s root AGENTS.md or CLAUDE.md into your own projects. Those configure contributors to the repo itself. Reusable assets live under skills/.

  


  

    Fastest route
    
Universal installation

    
Works for any agent supported by the open skills CLI.

    

      
npx --version

      
npx skills add addyosmani/agent-skills --list

      
npx skills add addyosmani/agent-skills

    

    
The target list evolves. Run --list to see what’s supported now, then restart your agent so skill discovery refreshes.

  


  

    Native setups
    
Find your agent

    
Use the native route where your agent provides one.

    
    

      
Claude Code
Plugin marketplace.

        
/plugin marketplace add https://github.com/addyosmani/agent-skills.git

        
/plugin install agent-skills@addy-agent-skills

      
Antigravity
Install, then restart and start a fresh session.

        
agy plugin install https://github.com/addyosmani/agent-skills.git

        
agy plugin list

      
Gemini CLI
Confirm with /skills list.

        
gemini skills install https://github.com/addyosmani/agent-skills.git --path skills

      
Cursor
Sync into .cursor/skills/.

        
git clone https://github.com/addyosmani/agent-skills.git

      
Codex CLI (v0.122+)
Plugin marketplace.

        
codex plugin marketplace add addyosmani/agent-skills

        
codex plugin add agent-skills@agent-skills

      
GitHub Copilot
Custom agent files must end in .agent.md.

        
copilot plugin install addyosmani/agent-skills

      
Windsurf
Keep it to 2–3 essential skills.

        
cat skills/test-driven-development/SKILL.md > .windsurfrules

      
OpenCode
Uses the universal CLI.

        
npx skills add addyosmani/agent-skills

      
Command Code
Global install.

        
cmd skills add addyosmani/agent-skills --global

      
Kiro
Place skills under .kiro/skills/.

    

    
No match. Try the universal command above.

  


  

    Troubleshooting
    
Common issues

    
The fastest fix for each.

    
agy is not recognized
Restart PowerShell and check your PATH.

    
Plugin installed but no skills show up
Restart the agent and start a new session.

    
Cursor can’t see the skills
Confirm that .cursor/skills/<name>/SKILL.md exists.

    
Codex plugin command is missing
Check that your CLI is v0.122 or newer.

    
A skill isn’t triggering
Check the skill’s name and description, or invoke it explicitly where your agent supports it.
